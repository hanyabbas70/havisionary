Sie können eine der folgenden Lösungen ausprobieren:
1. Warten: Warten Sie von einigen Stunden bis zu einem ganzen Tag — das System benötigt möglicherweise Zeit, um den neuen Kaufstatus automatisch zu erkennen.
2. Aktualisieren Sie den App-Status über den Kaufdialog: Tippen Sie in der App auf den Kaufdialog, ein weiterer Dialog wird geöffnet — wählen Sie dort „Kaufen" aus. Sie gelangen nicht zum Zahlungsbildschirm; stattdessen erscheint sofort eine Meldung, die bestätigt, dass Sie das Produkt bereits besitzen — es wird keine Zahlung erhoben. Dies ist sicher und hilft dem System, Ihren vorherigen Kauf sofort zu erkennen. Starten Sie die App danach neu, und sie sollte als Pro angezeigt werden.
3. Kontaktieren Sie den Support: Öffnen Sie das Seitenmenü → tippen Sie auf das Zahnrad-Symbol → wählen Sie „Über die App". Am Ende finden Sie eine eindeutige, mit Ihrem Konto verknüpfte ID mit einem E-Mail-Symbol daneben. Tippen Sie darauf und beschreiben Sie das Problem kurz, unser Support-Team wird es manuell lösen.
