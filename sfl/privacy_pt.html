1. Informações Gerais

Obrigado por escolher a “HA VISIONARY”. Estamos comprometidos em proteger a privacidade de nossos usuários. Nosso principal objetivo é proteger as informações dos usuários enquanto você utiliza o aplicativo Spectra Flashlight e oferecer melhores serviços.

Esta política se aplica às informações coletadas através do aplicativo ou de comunicações eletrônicas relacionadas.

Por favor, leia esta política com atenção. Se você não concorda com nossa política, por favor, não faça o download ou utilize o aplicativo. Ao utilizar o aplicativo, você concorda com esta Política de Privacidade.

Para qualquer dúvida, entre em contato conosco através do e-mail: havisionary.support@gmail.com.

2. Coleta e Uso de Dados

Informações fornecidas por você

Ao utilizar o aplicativo, entrar em contato conosco ou enviar feedback, podemos receber seu nome e endereço de e-mail.

Coleta Automática de Dados

Ao utilizar o aplicativo, podemos coletar automaticamente:

  • Dispositivo: Tipo de dispositivo e identificador para suporte técnico.
  • Analytics: Utilizamos o Google Analytics para medir padrões de uso.
  • Dados de Registro (Log Data): Em caso de erros, endereços IP e informações do sistema operacional podem ser coletados.

Permissões Necessárias

O aplicativo requer as seguintes permissões:

Lanterna (FLASHLIGHT) Necessário para as funcionalidades básicas do aplicativo.
Localização (LOCATION) Necessário para exibir a localização no mapa. Não armazenamos dados de localização geográfica do usuário.

3. Segurança dos Dados

A privacidade de seus dados é muito importante para nós. Seguimos protocolos aceitos para proteger os dados.

Para usar nosso aplicativo não é necessário criar uma conta, portanto, não coletamos dados pessoais. Todas as informações permanecem no seu dispositivo e são excluídas quando você desinstala o aplicativo.

4. Direitos do Usuário

Concedemos aos nossos usuários os seguintes direitos:

  1. Direito de acesso: Direito de obter detalhes sobre os dados pessoais processados.
  2. Direito de retificação: Direito de corrigir dados incorretos.
  3. Direito de revogação: Direito de retirar o consentimento a qualquer momento.
  4. Direito de exclusão: Direito de excluir dados sob certas condições.
